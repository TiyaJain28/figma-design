## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd elementum
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```


Preview the production build:

```bash

```
